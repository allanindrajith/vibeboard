# VibeBoard

**Ship-to-Revenue analytics for vibecoders.**

One unified dashboard across every app you vibe-coded in Cursor, Lovable, Bolt, or v0. Track visitors → signups → Stripe MRR → churn with zero manual event schemas and plain-English Kill / Optimize / Scale verdicts.

- **Live:** https://vibeboard.itsallan.me
- **Stack:** Vite 8 · React 19 · TypeScript · Tailwind CSS v4 · Lucide Icons

## Run Locally

```bash
npm install
npm run dev
```

## Build & Deploy

Pushes to `main` automatically build and deploy to GitHub Pages (`vibeboard.itsallan.me`) via `.github/workflows/deploy.yml`.
